# Che779 Emulator V1

Source Java của Emulator V1 nằm tại `source/`. JAR có sẵn từ archive ban đầu được giữ tại `prebuilt/Che779_Emulator.jar` để tham chiếu; đây không phải output build mới.

Build và chạy xem `../../docs/BUILD_AND_RUN.md`. Kiến trúc và giao thức IPC xem `../../docs/ARCHITECTURE.md` và `../../docs/IPC_PROTOCOL.md`.
